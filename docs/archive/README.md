# Archived Documentation Policy

The files under `docs/audits`, `docs/architecture`, `docs/backend` and related
folders that describe completed sprints are historical evidence. They are not
current implementation contracts. Current product and architecture decisions
are defined by:

- `docs/architecture/ARCHITECTURE_CURRENT.md`
- `docs/architecture/SYSTEM_FLOW.md`
- `docs/architecture/DOMAIN_MODEL.md`
- `docs/product/CONSULTANT_FLOW.md`
- `docs/audits/LEGACY_INVENTORY.md`
- `docs/audits/LEGACY_REMOVAL_LOG.md`

Historical documents are retained to preserve auditability and are archived by
policy rather than silently deleted.
