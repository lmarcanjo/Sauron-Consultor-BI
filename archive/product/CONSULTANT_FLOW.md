# Consultant Flow

## Starting Point

Open `Empresas e Grupos` to register the group, company and unit. Then open
`Fontes de Dados` to import a file or connect a database.

## Confirming a Source

After import, open `Análise da fonte`. Review the found structure and suggested
fields, confirm the selected information, then return to `Fontes de Dados` to
activate the source. This is the only structural confirmation step.

## Working With Results

Use `Visão Executiva` for the source preview and summary. Open only the
Financeiro, Comercial or Pessoas results that are applicable to the confirmed
source. A result that lacks information explains what is missing and points
back to `Análise da fonte` instead of asking for the same source again.

## Preparing the Conversation

Use `Apresentações`, then `Preparação da Reunião`, and finally the session flow.
The output is based on the active source and certified metrics available for the
selected context.

## Sprint 18 Validation Note

The canonical flow was exercised with the consultant's Honda spreadsheet:
context, import, source analysis, confirmed view, results, reload,
presentation, snapshot, meeting and minutes completed without browser errors.
The local journey uses the existing local import mode. SQL validation requires
the consultant's VPN to be active; without it the product must report the
connectivity failure and preserve the local spreadsheet flow.
