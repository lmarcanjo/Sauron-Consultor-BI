# SPRINT 22 — UI Simplification & Vocabulary Enforcement

## Simplificação de Linguagem e Eliminação de Termos Técnicos

Nenhum termo interno de desenvolvimento é exibido para o consultor na interface de aprendizado:

| Termo Técnico Proibido | Linguagem Simplificada do Consultor Adotada |
| --- | --- |
| `Dataset` / `ActiveDataset` | **Fonte de dados / Dados da Empresa** |
| `Profiling` / `Source Profile` | **Aprendizado / Descobertas da Fonte** |
| `Semantic Role` / `Mapping` | **Sugestão de Interpretação** |
| `Inference` | **Compreensão da empresa** |
| `Container` / `Block` | **Tabelas / Estruturas encontradas** |
