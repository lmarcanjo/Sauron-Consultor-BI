# SAURON DESIGN LANGUAGE — MICROCOPY & COPYWRITING

A linguagem falada dentro do Sauron OS molda a postura consultiva do produto. Evitamos jargões de TI frios ou mensagens de erro desleixadas. Cada termo deve evocar rigor estratégico, senioridade e segurança corporativa.

---

## 1. PRINCÍPIO DA LINGUAGEM CONSULTIVA (SDL 13)

• **Tom de Voz Sênior**: Falamos como conselheiros de confiança. Usamos verbos fortes e substantivos de alto impacto empresarial (ex: "Sessão Executiva", "Ritual de Alinhamento", "Ata de Reunião", "Ação Tática", "Gargalo Operacional").
• **Eliminação de Termos Genéricos**: É expressamente proibido o uso de termos vazios ou desinteressantes como "Ok", "Enviar", "Clique Aqui" ou "Erro Desconhecido". Substitua por ações contextualizadas claras.

---

## 2. DICIONÁRIO DE SUBSTITUIÇÕES SEMÂNTICAS

Para manter o rigor e a consistência da escrita:

| ❌ Evitar (Linguagem ERP/TI) | ✅ Preferir (Linguagem Consultiva Sauron) |
| :--- | :--- |
| "Criar Reunião" | "Iniciar Ritual" / "Nova Sessão" |
| "Salvar Notas" | "Sincronizar Decisões" / "Registrar Decisão" |
| "Editar Projeto" | "Atualizar Caso" |
| "Importar Arquivo" | "Sincronizar Planilha de Dados" |
| "Lista de Tarefas" | "Plano de Ação Tático" |
| "Fazer Backup" | "Sincronizar Snapshot" |
| "Conectar ao BD" | "Sincronizar Banco Corporativo" |
| "Ocorreu um Erro" | "Desvio de Conexão Detectado" |
| "Sucesso" | "Operação Sincronizada com Sucesso" |

---

## 3. COMPORTAMENTO EM CASO DE FALHAS

Em caso de erros técnicos de conexão (ex: falha de VPN ou DNS de banco de dados):
• Explique de maneira objetiva e educada qual recurso falhou.
• Forneça uma instrução direta e viável para o consultor resolver o desvio sem expor caminhos de código internos ou logs técnicos desnecessários no corpo principal do erro.
