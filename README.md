# Sauron Consultor BI Agent OS

Sistema consolidado e otimizado para Inteligência B2B, Controladoria e Apresentações Executivas.

## Comandos

- `npm run dev`: Inicia o sistema
- `npm run build`: Cria versão para produção
- `npm run test:e2e`: Executa testes automáticos do fluxo de apresentação e DRE.

## Pilares do App

- **SaaS B2B**: Múltiplos segmentos e tenants.
- **Controladoria Assistida**: "DRE Inteligente" auto-categoriza contas através de IA ou heuresticas.
- **Apresentador (Meeting Mode)**: Transformação de relatórios em slides gerenciais interativos para não assustar o cliente visualmente na hora de apresentar dados chatos.
